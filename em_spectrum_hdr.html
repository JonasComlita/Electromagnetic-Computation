Color generation: Each pixel uses oklch(0.68 0.32 H) where H sweeps 270° (violet) → 0° (red). oklch is perceptually uniform — equal hue steps look visually equal, unlike HSL. float16 stores 65,536 levels per channel. Rec2020 gamut covers ~75% of human-perceivable color vs sRGB's ~35%. Display caveat: HDR colors only render beyond sRGB on an HDR-capable monitor with the browser in HDR mode.
