# Lesson 2: Relativity and Lag

Lesson 1 answered "what the field state is." This lesson answers "why observers disagree about that same state."

When observer velocity changes, measured relationships between components change. The field did not become random; your frame changed.

## Learning goals

By the end of this lesson, you should be able to:

- Explain why changing `v/c` changes observed phase and magnitude relationships.
- Interpret Doppler scaling, simultaneity offset, and gamma-driven effects.
- Distinguish what is physically transformed from what is only visualized conceptually.

## Key idea: frame dependence

The same physical event can be described differently by different observers.

In the panel, velocity affects:

- `doppler factor`: observed compression/expansion of oscillation patterns.
- `simultaneity offset`: "same time" slices differ across moving frames.
- `gamma`: scaling factor that grows as `|v/c|` approaches 1.

## Why this matters before architecture

If you skip frame effects, architecture comparisons can be misleading. You would be comparing machines on a simplified signal that hides meaningful transformation cost.

## Advanced lens

Think in terms of coordinate transforms and invariants. The six-value payload is re-expressed under frame mapping.

## Common misconception

"Relativity only matters at extreme speeds."

The strongest effects appear near `c`, but the conceptual structure is present at any nonzero relative velocity.

## Inline Diagram
